# Linga — Intro Card

One-page intro card hosted on GitHub Pages.

- Live URL: https://lingaprasad-2008.github.io/MY-INTRO/
- Buttons on the card: Call (tap-to-call), Instagram, LinkedIn, and "Copy details" (copies my full intro to the clipboard).

## Update your details
Edit `index.html`, then commit and push — Pages auto-deploys from the `main` branch.

## Offline / printed copy
A self-contained QR (`intro_card/qr_linga_intro.png`) and a local printable copy of the card live in `../intro_card/` — no hosting needed.
